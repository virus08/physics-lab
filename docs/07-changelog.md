# บันทึกการเปลี่ยนแปลง (Changelog)
## Physics Lab

รูปแบบ: เวอร์ชันของระบบนับแยกจากเอกสาร เพิ่มเลขกลางเมื่อส่งมอบบทใหม่ เพิ่มเลขท้ายเมื่อแก้ไขโดยไม่เพิ่มชุด

## [1.0.0] - 2026-10-27

- แบบจำลองใช้งานได้จริงครบ 76 ชุด (S1.1 ถึง S20.5) ใน `lab/sims/` ทุกชุดสถานะ `ready` ในแคตตาล็อก ครอบคลุม 195 เรื่องของสรุป 20 บท
- ไลบรารีร่วม `lab/lib/physlab.js` + `physlab.css`: เอนจินก้าวเวลาคงที่ ตัวควบคุมพารามิเตอร์ (range, number, choice, toggle, text) ชุดค่าสำเร็จรูป จุดลาก (map คืนค่าตัวเดียวหรือหลายพารามิเตอร์พร้อมกัน) ค่าอ่าน สูตรแทนค่า กราฟตามเวลา เนื้อหา ตารางอ้างอิง ธีมมืด ลิงก์ที่จำค่า บันทึกภาพ และเสียงผ่าน Web Audio (บท 12)
- ฮุก `onParam(key, value, params, state)` สำหรับแบบจำลองที่ต้องอัปเดตเสียงหรือสถานะทันทีเมื่อปรับค่า
- แคตตาล็อก `lab/index.html` สร้างจาก `node lab/tools/build-catalog.mjs` ฝัง catalog ไว้ในหน้าเพื่อเปิดจาก file:// ได้
- ชุดทดสอบ `node --test lab/tests/*.test.mjs` ผ่าน 83 รายการ (ไลบรารี ฟิสิกส์ ความครอบคลุม และ smoke ทุกชุดด้วย Playwright)
- ตรวจภาพหน้าจอทุกชุดบนเดสก์ท็อปและแก้ป้ายซ้อนทับแล้ว
- เผยแพร่เป็น Artifact ส่วนตัว https://claude.ai/artifact/WJwmbEAKNb9keHV2u4JHpZ
- เผยแพร่สาธารณะบน Azure Static Web Apps https://blue-bush-0542be600.1.azurestaticapps.net (ดู 06-runbook.md ข้อ 2.1)
