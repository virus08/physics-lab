## 1. สิ่งที่ต้องมี

ไม่มี ระบบเป็นไฟล์ HTML ล้วน ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่ออินเทอร์เน็ต ต้องการแค่เบราว์เซอร์รุ่นปัจจุบัน

## 2. วิธีเปิดใช้

| วิธี | ขั้นตอน | เหมาะกับ |
|---|---|---|
| เปิดไฟล์ตรง | ดับเบิลคลิก `lab/index.html` | ใช้เองหรือสาธิตในห้องเรียน |
| เซิร์ฟเวอร์ในเครื่อง | `python3 -m http.server 8080 --directory lab` แล้วเปิด `http://localhost:8080` | ให้หลายเครื่องในวง LAN เดียวกันเปิดผ่าน IP ของเครื่องครู |
| คัดลอกโฟลเดอร์ | คัดลอก `lab/` ทั้งโฟลเดอร์ลง USB, Google Drive หรือระบบจัดการเรียนรู้ของโรงเรียน | แจกให้นักเรียนเก็บไว้เปิดเอง |
| โฮสต์สถิต | อัปโหลด `lab/` ขึ้นบริการโฮสต์ไฟล์สถิตใดก็ได้ (เช่น GitHub Pages) | ให้นักเรียนเปิดจากที่บ้านด้วยลิงก์ |
| Azure Static Web Apps (ใช้อยู่) | ดูข้อ 2.1 | ลิงก์สาธารณะ https://blue-bush-0542be600.1.azurestaticapps.net |

ทุกวิธีใช้ไฟล์ชุดเดียวกัน ไม่ต้องแก้อะไรก่อนย้าย (NFR-T2)

### 2.1 Azure Static Web Apps

ทรัพยากร: resource group `physics-lab-rg` (East Asia) · แอป `physics-lab` SKU Free · โฮสต์ `blue-bush-0542be600.1.azurestaticapps.net` · โดเมน `phy.fuangmali.info` (CNAME ที่ Google Cloud DNS ชี้ไปโฮสต์ Azure ใบรับรอง TLS ออกให้อัตโนมัติ) · สร้างเมื่อ 2026-10-27 ด้วยบัญชี Azure ของเจ้าของโปรเจกต์

ขั้นตอนอัปเดตเว็บ (ต้อง `az login` และมี `swa` CLI)

```bash
cd /Users/ananya/cinematic-studio
node lab/tools/build-catalog.mjs && node --test lab/tests/*.test.mjs
T=$(az staticwebapp secrets list -n physics-lab -g physics-lab-rg --query properties.apiKey -o tsv)
swa deploy lab --deployment-token "$T" --env production
```

การเผยแพร่ใช้เวลาประมาณ 1 นาที ไม่มี GitHub Actions เพราะโปรเจกต์ไม่มี remote บน GitHub ถ้าต้องการลบเว็บใช้ `az group delete -n physics-lab-rg`


## 3. การส่งกรณีตัวอย่างให้นักเรียน

1. เปิดแบบจำลอง ตั้งค่าที่ต้องการ
2. กด "คัดลอกลิงก์" ได้ URL ที่ฝังค่าไว้ เช่น `ch07-s1-projectile.html?u=25&theta=30`
3. ส่งลิงก์ หรือสร้าง QR จากลิงก์ ใส่ท้ายสไลด์หรือท้ายวิดีโอ
4. นักเรียนเปิดแล้วได้ค่าเดียวกันทันที

## 4. การอัปเดต

1. แทนที่โฟลเดอร์ `lab/` ทั้งโฟลเดอร์ด้วยเวอร์ชันใหม่ (ไม่ต้องแทนทีละไฟล์)
2. เปิด `index.html` ตรวจว่าจำนวนแบบจำลองพร้อมใช้ตรงกับที่ระบุใน 07-changelog.md
3. ถ้าโฮสต์สถิต ให้ล้างแคชของเบราว์เซอร์หรือเพิ่มเลขเวอร์ชันท้ายลิงก์

## 5. การย้อนกลับ

ทุกเวอร์ชันอยู่ใน git ของโปรเจกต์ ย้อนกลับด้วยการ checkout commit ของบทก่อนหน้าแล้วคัดลอก `lab/` ใหม่ ไม่มีฐานข้อมูลหรือข้อมูลผู้ใช้ที่ต้องกู้คืน

## 6. ตรวจสอบหลังติดตั้ง

- [ ] เปิด `index.html` เห็นรายการครบและกรองได้
- [ ] เปิดแบบจำลองหนึ่งชุด กดเล่น ภาพขยับ ค่าอ่านเปลี่ยน
- [ ] ลองบนมือถือหนึ่งเครื่อง
- [ ] ถ้าใช้เซิร์ฟเวอร์ เปิดจากเครื่องอื่นในวงเดียวกันได้

## 7. แก้ปัญหาหน้างาน

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| เปิดไฟล์แล้วหน้าว่าง | เบราว์เซอร์เก่ามาก หรือเปิดไฟล์จากในไฟล์ zip โดยไม่แตก | แตก zip ก่อน และใช้เบราว์เซอร์รุ่นปัจจุบัน |
| รายการในแคตตาล็อกไม่ขึ้นเมื่อเปิดจาก file:// | เบราว์เซอร์บล็อกการโหลด catalog.json | ระบบจะใช้สำเนาที่ฝังไว้ ถ้ายังไม่ขึ้นให้เปิดผ่านเซิร์ฟเวอร์ในเครื่อง |
| ไม่มีเสียงในบท 12 บน iPhone | ยังไม่ได้แตะหน้าจอ | กดปุ่มเล่นหนึ่งครั้ง และตรวจว่าไม่ได้เปิดโหมดเงียบ |

| ตัวอักษรบางตัวเป็นกล่อง | ฟอนต์ระบบไม่มีสัญลักษณ์บางตัว | อัปเดตระบบปฏิบัติการ ระบบใช้เฉพาะสัญลักษณ์มาตรฐาน ถ้ายังพบให้แจ้งเป็น known issue |
| ค่าที่ตั้งหายเมื่อเปิดใหม่ | เบราว์เซอร์ปิด localStorage | เป็นพฤติกรรมปกติ ใช้ "คัดลอกลิงก์" เก็บค่าแทน |
