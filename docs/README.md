# เอกสาร Physics Lab ตามวงจรพัฒนาซอฟต์แวร์ (SDLC)

ชุดเอกสารของระบบ Physics Lab แบบจำลองฟิสิกส์เชิงโต้ตอบสำหรับนักเรียน จัดตามขั้นของ SDLC ขั้นละหนึ่งเอกสาร อ่านเรียงตามลำดับได้ หรือเปิดเฉพาะขั้นที่ต้องใช้

| ขั้น | เอกสาร | ใช้ตอบคำถาม |
|---|---|---|
| 1 วางแผน | [01-project-plan.md](01-project-plan.md) | ทำอะไร เพื่อใคร ใครทำ ทำตามลำดับไหน เสี่ยงตรงไหน |
| 2 ความต้องการ | [srs.md](srs.md) | ระบบต้องทำอะไรได้บ้าง ดีแค่ไหน ตรวจรับอย่างไร |
| 3 ออกแบบ | [03-sdd.md](03-sdd.md) | โครงสร้างโค้ดเป็นอย่างไร ไลบรารีร่วมทำงานอย่างไร แบบจำลองแต่ละชุดเขียนอย่างไร |
| 4 พัฒนา | [04-developer-guide.md](04-developer-guide.md) | จะเพิ่มแบบจำลองใหม่ทีละขั้นอย่างไร มาตรฐานโค้ดคืออะไร |
| 5 ทดสอบ | [05-test-plan.md](05-test-plan.md) | ทดสอบอะไร ด้วยอะไร ผ่านเมื่อไร |
| 6 ติดตั้งใช้งาน | [06-runbook.md](06-runbook.md) | เอาไปให้นักเรียนใช้อย่างไร อัปเดตอย่างไร แก้ปัญหาหน้างานอย่างไร |
| 7 บำรุงรักษา | [07-changelog.md](07-changelog.md), [07-known-issues.md](07-known-issues.md) | เปลี่ยนอะไรไปบ้าง ปัญหาที่รู้แล้วมีอะไร |
