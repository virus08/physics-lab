## 1. วัตถุประสงค์

พิสูจน์ว่าแบบจำลองทุกชุด (1) คำนวณตรงตามฟิสิกส์ (2) เปิดใช้ได้ทุกเบราว์เซอร์ที่กำหนด (3) ให้ผลเหมือนกันทุกครั้ง และ (4) ครอบคลุมเนื้อหาครบ 195 เรื่อง ก่อนส่งตรวจรับ

| PHY-S6.2 | การชน 1 มิติ | m₁ = 2, m₂ = 1, u₁ = 3, u₂ = 0 ยืดหยุ่น | v₁′ = 1, v₂′ = 4 โมเมนตัมรวมต่างไม่เกิน 1e-9 Ek ต่างไม่เกิน 1e-6 |
| PHY-S9.5 | คลื่นนิ่ง | L = 2, n = 3 | บัพที่ x = 0, 0.667, 1.333, 2 ภายใน 0.1% ของ L |
