# Physics Lab — แบบจำลองฟิสิกส์เชิงโต้ตอบ ม.ปลาย 20 บท

แบบจำลองฟิสิกส์ 76 ชุด ครอบคลุม 195 เรื่องของฟิสิกส์มัธยมปลาย 20 บท ให้นักเรียนกดเล่น ลากค่า และดูผลทันที ทุกชุดเป็น HTML5 + JavaScript ล้วน เปิดจากไฟล์ในเครื่องได้โดยไม่ต้องติดตั้งอะไรและไม่ต้องต่ออินเทอร์เน็ต

**ใช้งานออนไลน์:** https://phy.fuangmali.info (สำรอง: https://blue-bush-0542be600.1.azurestaticapps.net)

## สิ่งที่มีในแต่ละชุด

- ภาพเคลื่อนไหวที่คำนวณจากสมการฟิสิกส์จริง (เอนจินก้าวเวลาคงที่ ไม่ใช่แอนิเมชันสำเร็จรูป)
- แผงปรับค่า ชุดค่าสำเร็จรูป และจุดที่ลากบนภาพได้
- ค่าอ่าน สูตรพร้อมการแทนค่า และกราฟตามเวลา
- เนื้อหาสรุปของเรื่องนั้น ข้อแนะนำ "ลองทำดู" และตารางอ้างอิง
- ปุ่มคัดลอกลิงก์ที่ฝังค่าไว้ ใช้ส่งโจทย์ให้นักเรียนเปิดได้ค่าเดียวกัน
- บท 12 (เสียง) มีเสียงจริงผ่าน Web Audio

## วิธีเปิดใช้

| วิธี | ขั้นตอน |
|---|---|
| เปิดไฟล์ตรง | ดับเบิลคลิก `index.html` |
| เซิร์ฟเวอร์ในเครื่อง | `python3 -m http.server 8080` แล้วเปิด http://localhost:8080 |
| โฮสต์สถิต | อัปโหลดทั้งโฟลเดอร์ขึ้น Azure Static Web Apps, GitHub Pages หรือเว็บโรงเรียน (ดู `docs/06-runbook.md`) |

## โครงสร้าง

```
index.html        หน้าแคตตาล็อก (ฝังสำเนา catalog ไว้ในหน้า)
lib/physlab.js    ไลบรารีร่วม: เอนจิน แผงควบคุม การวาด กราฟ เสียง ธีม
lib/physlab.css   สไตล์ทุกหน้า
sims/             แบบจำลอง 76 ไฟล์ ชื่อ chNN-sM-<slug>.html
data/catalog.json รายการแบบจำลอง (สร้างด้วย tools/build-catalog.mjs)
docs/             เอกสาร SDLC: แผน SRS SDD คู่มือนักพัฒนา แผนทดสอบ runbook changelog
tests/            ชุดทดสอบ (node --test + Playwright)
tools/            สคริปต์สร้างแคตตาล็อก
```

## สำหรับผู้พัฒนา

```bash
npm install          # ติดตั้ง playwright-core สำหรับ smoke test (ต้องมี Chromium ในเครื่อง)
npm test             # ทดสอบไลบรารี ฟิสิกส์ ความครอบคลุม และเปิดทุกหน้า
npm run catalog      # สร้าง data/catalog.json ใหม่หลังเพิ่มหรือลบแบบจำลอง
```

วิธีเพิ่มแบบจำลองใหม่ทีละขั้นอยู่ใน `docs/04-developer-guide.md` โครงสร้างโค้ดอยู่ใน `docs/03-sdd.md`
